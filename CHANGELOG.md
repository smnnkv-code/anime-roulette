## [1.0.0] - 2026-10-20

### Added
- Интерактивный генератор случайного аниме с физической симуляцией вращения барабана (60 FPS) и ретро-звуками аркадного автомата.
- Встроенный пиксельный ретро-плеер (`RetroPlayer`) с парсингом доступных озвучек и серий через Kodik embed API.
- Интеграция с MyAnimeList (MAL API v2) для авторизации и синхронизации списков пользователя (Watching, Plan to Watch, Completed и др.) с контролем дедлайна пагинации.
- Поиск и обогащение метаданных (русскоязычные названия, постеры, синопсис) через Shikimori API.
- Автономный генератор журнала изменений (`generate-changelog.js`) с автоматическим обобщением записей безопасности.
- Нагрузочный бенчмарк API и клиентских алгоритмов на базе Autocannon (`npm run test:perf`).
- Система мониторинга сбоев Sentry (@sentry/react, @sentry/node) с обязательной санитизацией PII и токенов.
- Автоматизированные пайплайны GitHub Actions для CI, публикации релизов и еженедельного security-аудита зависимостей.
- Предкоммитные проверки Husky и lint-staged (сканирование секретов, статический анализ Oxlint, запуск связанных тестов).

### Changed
- Оптимизирован алгоритм генерации ленты барабана (`buildReelStrip`) и взвешенного выбора (`pickWeighted`) до sub-millisecond задержек (< 0.5 мс на 5 000 элементов).
- Настроен 5-минутный TTL кэширования загруженных списков аниме в sessionStorage для экономии сетевого трафика.

### Fixed
- Устранена ошибка падения плеера при получении не-JSON ответа (HTML 504/500 от CDN) в `RetroPlayer.jsx`.
- Устранено дублирование номеров серий и сбой fallback-парсинга опций плеера в `api/get-episodes.js`.
- Предотвращено превышение общего таймаута функции (504) в `api/mal-list.js` при пагинации больших списков.
- Исправлена утечка таймера звуковых тиков при размонтировании компонента рулетки в `useSlotAnimation.js`.

### Security
- Усилена серверная валидация входных параметров и защита от SSRF при обращении к внешним медиа-провайдерам.
- Ограничен доступ к API доверенными источниками через единый модуль CORS (`api/_lib/cors.js`).
- Внедрены строгие заголовки `Content-Security-Policy` и директивы `sandbox` для изоляции сторонних фреймов плеера.
- Повышена безопасность хранения токенов авторизации сессии и исключена утечка конфиденциальных данных в ошибки сервера.
- Реализован автоматический pre-commit барьер против утечки секретов и файлов `.env*`.
